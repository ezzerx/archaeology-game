# Atelier audio — original assets

These 23 audio assets are original deterministic mathematical synthesis created
for ArchaeologyGame. No recordings, third-party sample packs, model outputs,
paid generation calls, voices or musical works were used.

Generator: `tools/audio/build_atelier_audio.py` (Python standard library).
The optional command-line dependency, FFmpeg/libvorbis, encodes the room Ogg.
Running the generator recreates the PCM masters, room stream, SHA-256 manifest,
and `work/audio/atelier-audition.wav` with a timing guide.

- Brush: filtered friction, asynchronous bristle modulation, tiny granular contacts.
- Chisel: damped inharmonic modes, broad mineral impact, a brief settling-chip tail.
- Precision Pick: fine damped contact with a short granular scrape.
- Abrasive tip: continuous fine-grit friction, driven only by actual removed crust.
- Blower: soft filtered turbulence; runtime attack/release supplies the breath.
- Workshop room: subdued air/ventilation, sparse quiet timber-settling transients;
  no music or speech.

Runtime imports are versioned: short impacts use mono IMA ADPCM in memory;
four continuous textures use mono PCM16 for exact loop seams; room ambience
uses streamed mono Vorbis. There is no run-time synthesis of these assets.

The two legacy protected/damaging Bone cues remain byte-identical and are still
generated by `MaterialAudio.synthesize`; they are not in this asset directory.

`manifest.json` records source PCM metrics and hashes. Quality checks read the
WAV masters, not ADPCM-encoded resource bytes. Listen to judge timbre and comfort;
signal checks do not establish human sound-design approval.
