ArchaeologyGame — P6A3.1 / Mastery & Readability

Version de test Windows portable. Décompresse tout le ZIP dans un dossier,
puis ouvre ArchaeologyGame.exe. Aucun éditeur ni installation requis.
Garder ArchaeologyGame.exe et ArchaeologyGame.pck côte à côte.

1–4 : outils. Clic gauche : travailler. Molette : zoom.
Clic droit glissé : déplacer la vue. Home : vue d'ensemble. R : recommencer.
Alt+Enter : plein écran. F7 : comparer P6A3 / P6A3.1 sans reset.
F12 : comparer anciens / nouveaux outils. H : panneau de comparaison.

À regarder : 100% atteignable sous garde-fous ; cercle Chisel plus petit sans
changement de sa vraie zone ; Condition lisible et dégâts visuels progressifs ;
saleté des os repérable près de la fin du nettoyage ; petite poussière quand le
Brush retire réellement la saleté. Archive / Keep Cleaning / reset conservés.

Les sons restent ceux d'avant. Claude servira à la future passe dédiée.
Le fossile 3D B-17, la lampe interactive et le musée ne font pas partie de cette
version. La validation du ressenti reste humaine. Pas de sauvegarde persistante
ni de télémétrie réseau du playtest natif.

Export officiel Godot 4.7.2. Vérifications faites sur Linux avec le même moteur ;
l'exécutable Windows doit être retesté sur le PC de maison.
