ArchaeologyGame — P6A3.2 / B-17 Tripo Skull Pilot

Windows 64 bits portable : décompresse tout le ZIP, puis ouvre ArchaeologyGame.exe.
Garde l'EXE et son PCK ensemble. Aucun éditeur ni installation requis.

1–4 : outils. Clic gauche : travailler. Molette : zoom. Clic droit glissé : vue.
Home : vue d'ensemble. R : recommencer. Alt+Enter : plein écran. H : panneau.
F6 : comparer crâne Tripo / os actuels, sans reset.
F7 : comparer la lisibilité P6A3.1. F12 : comparer les outils.

Premier pilote limité au crâne : véritable source Tripo, ajustée et réduite dans
Blender. Les autres os restent ceux du jeu actuel. Le raccord de silhouette est
encore grossier ; ce n'est pas le squelette final. La représentation actuelle
reste présente là où le mesh ne couvre pas correctement le champ physique.

À tester : fouiller jusqu'au crâne, comparer avec F6 à zoom 1x et 3x, nettoyer
au Brush, observer Film / Condition, travailler les bords au Pick, puis Archive,
Keep Cleaning et reset. Vérifier l'absence d'os dans la matrice intacte, de trous,
de flottement et de désaccord entre le point de travail et l'os visible.
Le test P6A3.1 reste inclus : 100% affichés sous garde-fous, cercle Chisel plus
petit, jauge Condition, dernières taches plus lisibles et poussière du Brush.

Gameplay, exposition, propreté et Condition conservent leurs règles. Sons actuels
conservés ; Claude servira à la future passe sonore. Pas de sauvegarde de session
ni de télémétrie réseau du playtest natif.

Export officiel Godot 4.7.2. Vérification moteur et captures sur Linux ; le
lancement de l'EXE Windows et la fluidité doivent être testés à la maison.
