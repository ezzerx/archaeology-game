ArchaeologyGame — Arrivages V1 / issue #27
Godot 4.7.2 — Windows x64

Extraire tout le ZIP dans un dossier, puis lancer ArchaeologyGame.exe.
Garder ArchaeologyGame.pck et LICENCES.txt avec l'executable.
Aucune installation de Godot necessaire pour cette version exportee.

Choisir un colis : cliquer sur une caisse (ou touches 1, 2, 3).
Liberer le loquet : cliquer dessus (ou E).
Ouvrir : glisser le couvercle vers le haut ; un clic ou E l'ouvre aussi.
Cliquer sur Preparer ce bloc pour rejoindre l'atelier.
Echap : revenir aux trois colis. Alt+Entree : plein ecran.

Atelier : conserver le bloc puis Voir au musee.
Musee : Nouveaux arrivages pour recommencer le parcours.
Retour aux arrivages a l'atelier demande confirmation pour un travail non conserve.
Les photos, scores et archives existantes restent conserves.

Tester la lisibilite des indices, l'ouverture, le confort des transitions,
les trois preparations et la restitution au musee apres fermeture/relance.
La decouverte reste dans le bloc : aucun fossile ne doit etre visible a l'ouverture.

Le passage atelier/musee utilise deux renderers et relance le processus :
un chargement avec changement de fenetre peut etre visible.
Cette version de test attend l'essai humain d'Antoine avant merge.
Le lancement Windows devra etre verifie sur le PC ; validation cloud sous Linux.
Les associations entre les trois colis et preparations sont fixes pour cet essai.
